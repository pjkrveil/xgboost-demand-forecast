모델을 불러오면 예측을 시작할 수 있습니다.
01

모델 불러오기

또는 내 모델 사용

config.json · model.json · climate_history.csv를 포함하세요. 원본 앱의 모델 보관함에서 내보낸 ZIP도 사용할 수 있습니다.

아직 불러온 모델이 없습니다.
02

예측 기간과 입력

기온이 없는 날짜는 N개년 통계로 보완합니다. 같은 날짜가 겹치면 아래쪽 파일의 행을 사용합니다.

03

기온 시나리오

N개년 기온 적용 구간 지정

±delta는 입력 기온에 더하거나 빼는 °C입니다. MC는 기온 보완이 필요한 날짜에 적용합니다. 시나리오 범위는 전체 예측 오차의 신뢰구간이 아닙니다.
